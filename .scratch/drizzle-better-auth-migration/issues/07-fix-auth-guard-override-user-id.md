# 07 — Remove `overrideUserId` Auth Guard Bypass in Server Actions

Category: bug
Status: completed

## Description
Server actions across `src/lib/actions/` (e.g. `transactions.ts`, `goals.ts`, `groups.ts`, `friends.ts`) currently accept an optional `overrideUserId` parameter intended for unit testing. This introduces a vulnerability where caller input can bypass session authorization.

## Requirements
- Remove `overrideUserId` parameter from all exported server actions.
- Ensure all server actions retrieve and enforce the authenticated user session via `auth.api.getSession({ headers: await headers() })`.
- Update unit test suites to mock `auth.api.getSession` or supply session headers instead of passing `overrideUserId`.

## Acceptance Criteria
- [x] No server action parameter accepts `overrideUserId`.
- [x] Unauthenticated calls strictly throw or return authorization error objects.
- [x] All Vitest unit tests pass cleanly.
